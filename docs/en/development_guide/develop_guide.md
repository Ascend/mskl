# MindStudio Kernel Launcher Development Guide

<br>

## 1. Prerequisites

### 1.1 Knowledge Preparation

Before starting development, you are advised to read [msKL Code Repository Architecture](./architecture.md) to learn about the project directory structure, core subsystems (operator invocation/automatic tuning), module dependencies, and data flow.

### 1.2 Environment Preparation

Follow [Operator Tool Development Environment Installation Guide](https://gitcode.com/Ascend/msot/blob/master/docs/en/common/dev_env_setup.md) to configure the environment.

## 2. Compilation and Packaging

Run the following command in the project root directory to compile `mskl`:

```shell
python build.py
```

### 2.1 Compilation Result Description

The compilation result is generated in the `output` directory:

```text
output/
|-- mindstudio_kl-26.0.0-py3-none-any.whl  # Installation package
```

### 2.2 Cleaning/Recompilation

Run the command in [Section 2](#2-compilation-and-packaging) again to automatically refresh the installation package generated by the compilation.

## 3. Running UT Tests

### 3.1 Running Tests

In the project root directory, run the following command to run the UT cases:

```shell
python build.py test
```

If the output is similar to the following, and the number of run test cases equals the number of passed test cases, it indicates success:

```text
[----------] 59 tests from CoreApi (8ms total)
```

```text
========== 59 passed in 2.05s ==========
```

### 3.2 Code Line Coverage

The coverage statistics depend on `coverage` and `pytest`. Run the following command in the project root directory:

```shell
bash test/generate_coverage.sh
```

The script measures the line coverage of the `mskl` product code only and writes the reports (text, XML, HTML, and `report.tar.gz`) to `build_ut/coverage`. The default line coverage threshold is 80%; the script returns a non-zero code when the coverage is below the threshold. Use `COVERAGE_THRESHOLD` to change the threshold:

```shell
COVERAGE_THRESHOLD=85 bash test/generate_coverage.sh
```

### 3.3 Cleaning the Test Environment

Delete the UT build directory and run the tests again:

```shell
rm -rf build_ut
```
